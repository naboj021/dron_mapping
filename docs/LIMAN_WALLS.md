# Паралелни инвентар: фасаде и зидни панели (Лиман)

Овај алат је засебан приказ истог локалног система за преглед фотографија. **Није доказ да на Лиману постоји азбест**: врста материјала се не може сигурно одредити искључиво визуелно. Користе се три нивоа доказа: сумња (подразумевано), стручна процена и лабораторијска потврда уз референцу документа.

## Покретање

Алат не преузима фотографије. Прво припреми нов директоријум са **копијама** JPG/PNG фотографија фасада/зидних панела, на пример `outputs/liman_walls/`. Немој мешати кадрове и анотације вртића са Лиманом.

```bash
git fetch origin
git switch -c feature/wall-facade-inventory --track origin/feature/wall-facade-inventory
./.venv/Scripts/python.exe -m pytest -v
./.venv/Scripts/python.exe -m drone_mapping.wall_review outputs/liman_walls --init --collection-id liman-photo-survey-01
./.venv/Scripts/python.exe -m drone_mapping.review_server outputs/liman_walls --port 8766
```

Отвори **http://127.0.0.1:8766/review.html**. Терминал са локалним сервером остави отворен. Ознаке се чувају у `outputs/liman_walls/annotations.local.json` независно од Цврчка.

Ако већ имаш `manifest.json` немој поново користити `--init` (постојећи инвентар се не преписује). У том случају покрени само:

```bash
./.venv/Scripts/python.exe -m drone_mapping.wall_review outputs/liman_walls
```

## Важна поља

- Раздвојити **целу зграду** од више **фасадних/зидних целина**; оријентација N/NE/E/... и опис су посебна поља. Празна KML референца остаје празна када изворна KML мапа није садржала објекат.
- Фасадне визуелне категорије: сумња на азбест у зидним/фасадним плочама, други материјал, замењен део фасаде, неодређено.
- Година изградње, година обнове фасаде, власништво, намена, стање материјала, могуће нарушавање/радови, прегледач, доказ и напомена.
- Локална ознака има `surface_type=wall`; не мешати је са полигоном крова.
- Не измишљати површину материјала или тип/садржај азбеста без одговарајуће основе.

## Границе овог првог корака

Ово је почетни алат за **локално мапирање са фотографија**. Није геореференцирани инвентар зграда Лимана, нема аутоматску препознавање фасадних панела, нити сарадњу више удаљених прегледача. За такав систем следеће треба SQLite/PostGIS, ревизиону историју сваког записа, уређивање по кориснику и контролисан приступ. Не постављати локалне снимке, приватне адресе и непроверене наводе на јавни GitHub.
