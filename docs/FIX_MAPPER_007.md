# fix/mapper-007 — са старих шест полигона на инвентар и ниво доказа

## Зашто се `frame_0009.jpg` приказује без ознака?

Генерисани `review.html` има фотографије и изворни `manifest.json`, али полигоне учитава **само** из `annotations.local.json` на диску. Претходно извезен `annotations_dji_fly_20260508_145004_226_1779100037300_video.json` није аутоматски постао локална база. То су два различита фајла.

Безбедна почетна миграција: копирај постојећи извезен JSON на локални диск, нпр. `outputs/cvrcak_frames/initial_annotations.json`. Увери се да **не постоји** `annotations.local.json` у истом директоријуму. Ако постоји, немој га брисати нити преписивати: користи HTML **Учитај раније извезен JSON** када се база учита и ручно утврди коју верзију треба задржати.

```bash
git fetch origin
git switch -c fix/mapper-007 --track origin/fix/mapper-007
./.venv/Scripts/python.exe -m pytest -v
./.venv/Scripts/python.exe -m drone_mapping.frame_review outputs/cvrcak_frames
./.venv/Scripts/python.exe -m drone_mapping.review_server outputs/cvrcak_frames \
  --seed outputs/cvrcak_frames/initial_annotations.json
```

Ако `annotations.local.json` већ постоји, покрени без `--seed`:

```bash
./.venv/Scripts/python.exe -m drone_mapping.review_server outputs/cvrcak_frames
```

Отвори **http://127.0.0.1:8765/review.html**, не `file://...`. На кадру 0009 провери да ли се приказује свих шест ранијих ознака и текст **Локално чување укључено**.

## Нова поља за инвентар

- Назив/опис и **положај кровне целине** (N, NE, E, SE, S, SW, W, NW, средишњи део).
- Тип посматрања (сумња на азбест, други покривач, замењени део, неодређено).
- **Ниво доказа:** `SUSPICION` подразумевано, `EXPERT_ASSESSMENT`, `LAB_CONFIRMED`. Последња два нивоа захтевају унету референцу документа. Само унос референце не доказује да је документ ваљан; стручне процене и извештаји лабораторије морају бити стварно прегледани.
- Прегледач (шифра/име); намена; јавно/приватно/мешовито; година изградње; година обнове; стање материјала; могуће нарушавање/приступ; напомена; ID матичног KML објекта.
- Празна година значи **непознато**, не 0. Празан KML ID значи да унети полигон нема одговарајућу ознаку у изворном KML-у.
- Више кровних целина може делити исти KML ID, али свака има свој `annotation.id`.

## Безбедност за више прегледача

Локални сервер има број верзије (`revision`). Приликом сваког аутоматског уписа проверава се да ли је клијент кренуо од актуелне верзије. У случају сукоба приказује се упозорење и **старија верзија се не уписује**; прво извези сопствене измене у засебан JSON, а затим освежи и усагласи податке. Сервер за сада ради **само на једном рачунару**, не преко јавног интернета; ово није пун систем паралелне сарадње.

Немој качити изворне видео-снимке, локалне JSON базе или KML локације приватних објеката на јавни GitHub.
