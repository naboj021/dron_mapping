# Ознаке више кровова на једном DJI кадру — локални преглед

**Без сервера и без слања снимака на интернет.** Постојећих 40 фотографија се не мења; `manifest.json` задржава изворни назив MP4 снимка и тражене временске позиције.

## Покретање (Git Bash)

```bash
git fetch origin
git switch -c feature/frame-annotation --track origin/feature/frame-annotation
./.venv/Scripts/python.exe -m pytest -v
./.venv/Scripts/python.exe -m drone_mapping.frame_review outputs/cvrcak_frames
explorer.exe "$(cygpath -w outputs/cvrcak_frames/review.html)"
```

`review.html` мора остати у истом директоријуму као JPEG кадрови. Отвориће се у локалном браузеру.

## Пример: девети кадар

1. Иди на **9/40**. Изворни фајл `frame_0009.jpg` је прихватљив: прегледач приказује и цело име оригиналног видео-снимка и временску позицију (према `manifest.json`).
2. Превуци правоугаоник око првог крова горе лево и упиши опис, категорију `Sumnja na vlaknocementni pokrivač`, напомену. Сачувај ознаку.
3. Понови за сваки преостали кров горе лево и десно. Један кадар може да има више засебних области.
4. За доњи део кадра који приказује вртић, по потреби додели засебну ознаку `Deo objekta vrtića`; историјски замењен део користи засебну категорију.
5. Ако знаш коју KML ознаку видиш, унеси њен **оригинални назив или ID** у опционално поље. То није аутоматско геореференцирање.
6. Кликни **Извези annotations JSON** и сачувај датотеку у локални `outputs/` директоријум. Прегледач не чува аутоматски; за наставак ручно учитај претходни JSON.

Сваки правоугаоник се чува као нормализоване координате `x,y,w,h` у опсегу 0..1, уз изворни видео, кадар, временску позицију, визуелну категорију, напомену и опциону KML везу.

Важно: **визуелна сумња није потврда присуства азбеста**. Пројекат мора одвојено чувати лабораторијски доказ и информације о извршеним радовима.

## Нова именовања кадрова

У `fix/mapper-002` измењено је **будуће** издвајање кадрова, нпр. `dji_fly_..._video__f0009__t000085000ms.jpg`. Постојећих 40 `frame_XXXX.jpg` не треба преименовати јер их постојећи `manifest.json` већ повезује са изворним MP4 снимком. Ако поново издвајаш кадар, користи *нови празан* излазни директоријум; немој преписивати оригинале.
