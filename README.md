# AZBEST MAPA — drone mapping

Python tools for planning and documenting supervised drone surveys of potentially asbestos-containing roofing materials.

**Scope:** geospatial planning, imaging geometry, mission preparation, and later evidence-aware classification. Photographs cannot confirm asbestos content.

**Safety:** This repository does not control drones, authorize flights, bypass geofencing, or export executable missions. Flight permissions, aerial-imaging permissions, operator supervision, and privacy compliance must be handled separately.
