# Inventar azbesta

Evidence-aware inventory of suspected asbestos-containing materials in buildings: roofs, facade and wall panels, floors, ceilings, insulation and other built-in products. Includes offline GIS/drone source documentation and a private local annotation workflow.

**Scope:** building/material inventory, evidence provenance, review workflows, private attributes, GIS, imagery and optional drone survey planning. Drone mapping is one input source, not the project name. Photographs and building age alone cannot establish asbestos content.

**Safety:** This repository does not control drones, authorize flights, bypass geofencing, or export executable missions. Flight permissions, aerial-imaging permissions, operator supervision, and privacy compliance must be handled separately.

Local working directory: `D:\PycharmProjects\mapiranje_dron`

Development starts with an offline DJI-independent planning module. See the development branch for the initial implementation.

**Project naming:** Inventar azbesta (public title); the existing GitHub repository name, Python module `drone_mapping`, and existing local folders remain unchanged for compatibility until a separate migration is planned. Current localhost server must not be exposed directly to the Internet.
